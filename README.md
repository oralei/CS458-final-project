# Gestureweave - Unity VR Game Prototype

Gestureweave is a VR game system prototype made in Unity. It utilizes controller and HMD tracking to detect certain gestures that are mapped to magic spells within the game. The game features three core gestures/spells:
- The **finger gun** gesture that allows you to shoot a homing fireball projectile.
- The **shield gesture** that summons a magic shield to block enemy projectiles.
- The **drink gesture** that allows the player to heal by drinking a potion.

### The Goal:
The goal of this prototype was to test how using gestures can enhance the game experience by providing an alternative input mapping, with a primary focus on familiarity and immersion.
